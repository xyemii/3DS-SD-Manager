# 3DS-SD-Manager
A Windows tool for your Nintendo 3DS SD card: find and delete homebrew, clean up macOS/Windows junk files, update Luma3DS &amp; co. from GitHub, format cards as FAT32, detect fake-capacity cards, and set up a starter pack for Old/New 3DS.
